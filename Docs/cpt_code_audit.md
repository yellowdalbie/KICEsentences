## 일괄 치환을 하지 않은 이유
코드 대부분이 **단순 표기 오타가 아니라 의미 오류**입니다. 예를 들어 `12미적02-02`는 사인법칙 풀이에 쓰였는데 로마자만 채워 `12미적Ⅰ-02-02`(미분가능성)로 바꾸면 개념 매핑이 오히려 틀어집니다. 이 프로젝트는 성취기준 매핑 자체가 검색 품질의 근간이므로, 파일별 교육과정 판단을 거쳐 개별 수정해야 합니다.
